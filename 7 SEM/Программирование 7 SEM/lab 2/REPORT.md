# Микросервисный агрегатор погоды

Проект реализует набор микросервисов для получения данных о погоде, формирования рекомендаций и ведения истории запросов.

## Функционал
- **Получение погоды**: запрашивает данные у OpenWeatherMap через `multiprocessing`.
- **Рекомендации**: анализирует погоду и дает советы пользователю.
- **История**: хранит данные о предыдущих запросах.

## Инструкция по запуску

### Локально:
1. Установите библиотеки: `pip install -r requirements.txt`.
2. Запустите: `python app.py`.
3. Сервис доступен по адресу: `http://localhost:8080`.

### Через Docker:
1. Соберите образ: `docker build -t weather-app .`.
2. Запустите контейнер: `docker run -p 8080:8080 weather-app`.

### Развертывание в Yandex Cloud:
1. Загрузите образ в Yandex Container Registry.
2. Создайте Serverless Container на основе загруженного образа.
3. Установите порт 8080 в настройках контейнера.

## Примеры использования
- `GET /weather?city=London` — получить данные о погоде.
- `GET /history` — посмотреть историю последних поисков.
- `POST /recommend` — отправить JSON с погодой для получения совета.
