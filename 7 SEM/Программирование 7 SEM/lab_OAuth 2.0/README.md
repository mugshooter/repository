# Отчет и Инструкция: Практика OAuth 2.0 в Python

## 1. Инструкция по запуску

### Предварительная настройка
1. Зарегистрируйте OAuth приложение на [GitHub](https://github.com/settings/developers).
2. В поле **Homepage URL** и **Authorization callback URL** укажите `http://localhost:8080` (или любой другой валидный адрес).
3. Скопируйте полученные `Client ID` и `Client Secret` в файл `oauth_client.py`.

### Запуск
1. Установите зависимости: `pip install -r requirements.txt`.
2. Запустите скрипт: `python oauth_client.py`.
3. Скопируйте ссылку из консоли в браузер, подтвердите доступ.
4. После перенаправления (страница может не открыться, это нормально), скопируйте весь URL из адресной строки браузера и вставьте его обратно в консоль скрипта.

## 2. Отчет по лабораторной работе

**Тема:** Реализация потока Authorization Code Flow.

### Описание процесса OAuth 2.0
В ходе работы был реализован стандартный сценарий делегирования доступа:
1. **Resource Owner (Я)**: Дал разрешение приложению через интерфейс GitHub.
2. **Client (Скрипт)**: Получил `Authorization Code` через редирект.
3. **Authorization Server (GitHub)**: Проверил код и секрет клиента, выдав `Access Token`.
4. **Resource Server (GitHub API)**: Предоставил данные профиля на основании валидного токена.



### Ответы на контрольные вопросы:
1. **Роли в OAuth 2.0**: Владелец ресурса (пользователь), Клиент (приложение), Сервер авторизации, Сервер ресурсов.
2. **Authorization Code**: Временный код, который нужен для безопасного обмена на токен. Он гарантирует, что токен передается напрямую между серверами, а не через браузер пользователя.
3. **Параметр state**: Используется для защиты от CSRF-атак. Он позволяет клиенту убедиться, что ответ пришел именно на тот запрос, который он инициировал.
4. **Refresh Token**: Используется для получения нового `access token` без участия пользователя, когда срок действия старого токена истек.

**Вывод:** В ходе работы был успешно изучен протокол OAuth 2.0. Библиотека `requests-oauthlib` значительно упрощает обработку параметров state и автоматизирует добавление токена в заголовки запросов.
