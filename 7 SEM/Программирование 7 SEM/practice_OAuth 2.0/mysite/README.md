# Практическая работа - Настройка OAuth 2.0 авторизации в Django приложении (Django + OAuth + Google)


## Выполненные части задания

### Улучшите приложение для голосований из лабораторных работ и реализуйте вход на сайт этого приложения через стандарт OAuth, при условии, что пользователь имеет учётную запись Google.



## Запуск проекта

1. Активировать виртуальное окружение:
```bash
source venv/bin/activate
```

2. Запустить сервер разработки:
```bash
cd mysite
python manage.py runserver
```

3. Открыть в браузере:
- Главная страница: http://127.0.0.1:8000/polls/
- Админка: http://127.0.0.1:8000/admin/
