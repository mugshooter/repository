# Инструкция по запуску: Weather Aggregator System

Данная система представляет собой распределенное приложение на базе Spring Boot и RabbitMQ для агрегации данных о погоде из внешних API.

## 1. Предварительные требования
* **Java**: JDK 17 или выше.
* **Maven**: для сборки модулей.
* **Docker**: для быстрого запуска брокера сообщений.
* **API Key**: получите бесплатный ключ на [OpenWeatherMap](https://openweathermap.org/api).


## 2. Подготовка инфраструктуры (RabbitMQ)
Система требует запущенного брокера RabbitMQ. Самый простой способ — запуск через Docker:

```bash
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management

```

* После запуска панель управления будет доступна по адресу: `http://localhost:15672` (логин/пароль: `guest`/`guest`).


## 3. Настройка и сборка

1. **Укажите API Ключ**:
В модуле `weather-consumer-service` откройте файл `WeatherConsumer.java` и замените значение переменной `API_KEY` на ваш актуальный ключ.
2. **Сборка проекта**:
Из корневой директории проекта выполните команду:
```bash
mvn clean install

```

## 4. Порядок запуска сервисов

Для корректной работы рекомендуется запускать микросервисы в следующей последовательности:

1. **Weather API Service** (Порт 8080): Принимает запросы.
2. **Weather Aggregator Service**: Собирает ответы воедино.
3. **Weather Consumer Service**: Выполняет запросы к внешнему API.
4. **Weather Frontend** (Порт 8081): Визуальный интерфейс.

*Запуск каждого сервиса осуществляется командой `mvn spring-boot:run` в соответствующей папке или через вашу IDE.*

## 5. Проверка работоспособности

1. Откройте в браузере страницу: `http://localhost:8081/index.html`.
2. В поле ввода введите список городов через запятую (например: `Moscow, Berlin, Tokyo`).
3. Нажмите кнопку **"Запросить погоду"**.
4. **Результат**:
* Фронтенд покажет ваш уникальный `Correlation ID`.
* В логах сервиса **weather-aggregator-service** вы увидите процесс накопления данных и финальный сформированный отчет, когда все воркеры пришлют ответы.


## 6. Устранение неполадок

* **Ошибки 401/403**: Проверьте правильность API ключа OpenWeatherMap.
* **Сообщения не доходят**: Проверьте в консоли RabbitMQ (порт 15672), созданы ли очереди `weather.requests` и `weather.responses`.
* **Порт занят**: Убедитесь, что `frontend` запущен на 8081, а `api-service` на 8080 (настраивается в `application.properties`).
