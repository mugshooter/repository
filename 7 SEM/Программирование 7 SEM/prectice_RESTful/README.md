# Практической работе: Task Management System

## 1. Инструкция по запуску
### Требования
- JDK 17 или выше
- Maven

### Шаги запуска
1. Скомпилируйте проект: `mvn clean install`
2. Запустите приложение: `mvn spring-boot:run`
3. Доступ к API: `http://localhost:8080/api/tasks`

### Авторизация
Приложение защищено Spring Security. Используйте Basic Auth:
- **Username**: admin
- **Password**: admin123

### Доступ к БД
Консоль H2 доступна по адресу `http://localhost:8080/h2-console`.
- JDBC URL: `jdbc:h2:mem:taskdb`
- User: `sa` / Pass: `password`

## 2. Отчет о выполнении
**Цель:** Разработка RESTful сервиса на Spring Boot с интеграцией БД и безопасности.

### Описание реализации:
1. **Сущность (Entity)**: Создан класс `Task` с использованием JPA аннотаций. Поля включают ID, название, описание, статус и дату создания.
2. **Уровень данных (Repository)**: Реализован `TaskRepository`, расширяющий `JpaRepository`. Это обеспечило автоматическую поддержку всех CRUD операций.
3. **REST Контроллер**: Реализованы эндпоинты:
   - `GET /api/tasks`: список всех задач.
   - `POST /api/tasks`: создание новой задачи.
   - `PUT /api/tasks/{id}`: редактирование существующей задачи.
   - `DELETE /api/tasks/{id}`: удаление.
4. **Безопасность**: Настроена базовая аутентификация в `application.yml`. Доступ к данным ограничен для неавторизованных пользователей.
5. **База данных**: Использована H2 Database в оперативной памяти (In-Memory), что позволяет быстро тестировать приложение без настройки внешних СУБД.



### Тестирование:
- Проверено создание задачи через POST-запрос в Postman с использованием Basic Auth.
- Подтверждено сохранение данных через H2 Console.
- Проверена блокировка запросов при отсутствии учетных данных (ошибка 401).

**Вывод:** Приложение успешно выполняет функции системы управления задачами, соответствует стандартам построения RESTful сервисов и требованиям безопасности.
