#### 3.1. Аннотированный список платформ для поиска IT-специалистов

Для подбора квалифицированных IT-кадров и поиска работы используются различные инструменты. Ниже приведен список наиболее актуальных ресурсов:

1.  **HeadHunter**

      * **Описание:** Крупнейший рекрутинговый портал в РФ.
      * **Достоинства:** Огромная база кандидатов, удобная фильтрация по стеку, интеграция с CRM-системами.
      * **Недостатки:** Высокая конкуренция за кандидатов, много "спам-откликов".
      * **Стоимость:** Платный доступ для работодателей (публикация вакансий, доступ к базе). Для соискателей — бесплатно.

2.  **Хабр Карьера**

      * **Описание:** Специализированная площадка для IT-специалистов от команды Хабра.
      * **Достоинства:** Максимально релевантная аудитория, возможность оценивать навыки кандидатов через активность на ресурсе.
      * **Недостатки:** Более узкая база по сравнению с HH, высокая стоимость размещения.
      * **Стоимость:** Платное размещение вакансий для работодателей.

3.  **Getmatch**

      * **Описание:** Сервис автоматизированного подбора с использованием ИИ.
      * **Достоинства:** "Умный" мэтчинг (кандидатов подбирают под стек), экономия времени рекрутера.
      * **Недостатки:** Относительно небольшая база по сравнению с гигантами.
      * **Стоимость:** Модель оплаты за успешный найм (Success Fee).

4.  **Telegram-каналы (например, "Get IT", "Junior IT", "Golang Job")**

      * **Описание:** Профильные сообщества и каналы с вакансиями.
      * **Достоинства:** Прямой контакт с кандидатом, оперативная связь, узкая специализация (есть каналы строго под Go/Python/etc).
      * **Недостатки:** Трудно автоматизировать поиск, высокий риск мошенничества или неактуальности.
      * **Стоимость:** Чаще всего бесплатно для кандидатов, платно для размещения вакансий от работодателей.

5.  **LinkedIn**

      * **Описание:** Глобальная профессиональная сеть.
      * **Достоинства:** Лучший инструмент для хедхантинга, рекомендации коллег, детальный профиль с историей проектов.
      * **Недостатки:** Требует использования VPN (в РФ), высокая стоимость premium-аккаунтов для рекрутеров.
      * **Стоимость:** Условно бесплатно, расширенный функционал платный.

6.  **GitHub / GitLab**

      * **Описание:** Платформы для хостинга IT-проектов.
      * **Достоинства:** Реальная оценка навыков через просмотр кода кандидата (особенно важно для Junior/Middle).
      * **Недостатки:** Отсутствие контактных данных в профиле, сложность ведения переписки как в HR-системе.
      * **Стоимость:** Бесплатно для поиска и просмотра.

7.  **Freelance-биржи (FL.ru, Freelance.ru)**

      * **Описание:** Площадки для поиска исполнителей на проектную работу.
      * **Достоинства:** Хорошо подходят для проверки кандидата на "боевой" задаче (тестовый проект).
      * **Недостатки:** Низкий порог входа, много низкоквалифицированных специалистов.
      * **Стоимость:** Комиссия сервиса за проведение сделки.
