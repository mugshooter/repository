# Гневнов А.Е., ВСР 11.2

### Права пользователя программного продукта

* **Использование по назначению:** Пользователь имеет право осуществлять любые действия, связанные с функционированием программы в соответствии с её прямым назначением, включая исправление явных ошибок.
* **Адаптация:** Разрешается вносить изменения исключительно для обеспечения функционирования программы на конкретных технических средствах пользователя или под управлением конкретных программ пользователя.
* **Создание резервной копии:** Пользователь может изготовить (или поручить изготовление) копии программы, если она предназначена только для архивных целей или для замены оригинала в случае его потери, уничтожения или непригодности.
* **Декомпилирование (изучение структуры):** Пользователь имеет право преобразовывать объектный код в исходный текст для изучения структуры и кодирования программы при соблюдении следующих условий:
    * Информация, необходимая для взаимодействия независимо разработанной программы с другими программами, недоступна из иных источников.
    * Декомпилирование затрагивает только те части программы, которые необходимы для организации такого взаимодействия.
    * Полученная информация не используется для создания новой программы, существенно схожей по виду с декомпилируемой, или для иных действий, нарушающих авторское право.
* **Ограничение использования копий:** Изготовленная резервная копия должна быть уничтожена, если дальнейшее владение экземпляром программы перестает быть законным.
