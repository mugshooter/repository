## Гневнов А.Е., Практика 8

### Аннотированный список архивов научных журналов (Технические науки и IT)

| № | URL | Примечание (содержание, коллекции, специфика) |
| :--- | :--- | :--- |
| 1 | [archive.neicon.ru](https://archive.neicon.ru) | **Архив «НЭИКОН».** Создан по госконтракту Минобрнауки. Содержит колоссальные коллекции полнотекстовых архивов ведущих зарубежных и отечественных научных издательств. Идеален для поиска фундаментальных работ по теории алгоритмов и кибернетике. |
| 2 | [elibrary.ru](https://elibrary.ru) | **РИНЦ (Научная электронная библиотека).** Крупнейший российский агрегатор. Содержит «Ядро РИНЦ» — лучшие публикации, индексируемые в Scopus и Web of Science. Позволяет искать статьи по DOI и отслеживать индекс цитируемости авторов. |
| 3 | [cyberleninka.ru](https://cyberleninka.ru) | **КиберЛенинка.** Научная библиотека открытого доступа. Построена на парадигме Open Science. Огромный массив статей по рубрикам «Компьютерные и информационные науки», «Электроника» и «Автоматика». Удобна тем, что сразу дает готовое библиографическое описание по ГОСТу. |
| 4 | [nbpublish.com](https://nbpublish.com/itmag/) | **Издательство Nota Bene.** Нас интересует журнал «Программные системы и вычислительные методы». Содержит свежие публикации (2024–2026 гг.) по языкам программирования, архитектуре ПО и ИИ. Все статьи проходят обязательное рецензирование. |
| 5 | [sibac.info](https://sibac.info/arhive-article?science=177) | **СибАК (Архив по информационным технологиям).** Специализируется на материалах научно-практических конференций. Полезен для поиска прикладных кейсов внедрения IT-решений, описания MVP и практических результатов экспериментов молодых ученых. |
